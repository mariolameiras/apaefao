# Apoiantes — guia para os colaboradores

A lista de apoiantes do site (página **Apoiantes** e faixa da página inicial) é gerida num quadro do Trello:
**APAEF – Gestão de Apoiantes**.

Não é preciso saber nada de informática: basta criar cartões e arrastá-los entre listas.

## As listas

| Lista | O que significa |
|---|---|
| **1. Novos Apoiantes** | Cartões acabados de criar. Ainda não aparecem no site. |
| **2. Em Validação** | Alguém está a confirmar a informação. Ainda não aparecem no site. |
| **3. Aprovados** | Aprovado: aparece no site em poucos minutos (até 5). |
| **4. Publicados** | Já está no site. O cartão é movido para aqui automaticamente. |
| **5. Arquivados** | Sai do site (a imagem é apagada). |

## Criar um apoiante

1. Na lista **1. Novos Apoiantes**, clica em **+ Adicionar um cartão**.
2. **Título** = nome do apoiante, como deve aparecer no site.
3. Abre o cartão e, em **Descrição**, escreve (uma linha por campo):

   ```
   Website: https://exemplo.pt
   Descrição: Uma frase sobre o apoiante.
   Categoria: Empresa
   Destaque: Não
   ```

   - **Website** — opcional. Se não tiver site, deixa a linha de fora.
   - **Descrição** — opcional, uma frase curta (aparece por baixo do nome).
   - **Categoria** — `Empresa`, `Instituição`, `Associação`, `Particular` ou `Outro`.
     Também podes usar as etiquetas coloridas em vez desta linha.
   - **Destaque** — `Sim` (ou a etiqueta vermelha **Destaque**) para aparecer primeiro e maior.
4. Em **Anexos**, carrega o logótipo ou uma foto (JPG ou PNG; até 10 MB).
   Sem imagem, o site mostra um ícone.
5. Arrasta o cartão para **2. Em Validação**.

## Publicar

1. Um administrador confirma a informação e arrasta o cartão para **3. Aprovados**.
2. Em poucos minutos o site é atualizado e o cartão passa sozinho para **4. Publicados**,
   com um comentário "✅ Publicado no site em …".
3. Se algo estiver errado, o cartão **fica em Aprovados** e recebe um comentário a explicar
   o que falta (por exemplo, um website inválido).

## Alterar ou remover

- **Alterar**: edita o cartão (em Aprovados ou Publicados). O site atualiza no ciclo seguinte.
- **Mudar a ordem**: arrasta os cartões dentro da lista. A ordem do site é a ordem da lista.
- **Remover**: arrasta o cartão para **5. Arquivados**. Desaparece do site.

## Notas

- Os logótipos são copiados para o site: se mudares a imagem no cartão, a imagem nova
  substitui a antiga. Se o nome do cartão mudar, a imagem é copiada de novo.
- Não é preciso escrever nada no GitHub. O quadro é a única fonte de verdade.
